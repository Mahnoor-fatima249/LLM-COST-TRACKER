Integrate LLM Cost Tracker into your application

1. Register & Get Token

POST /api/auth/register
curl -X POST http://localhost:8000/api/auth/register \
  -H "Content-Type: application/json" \
  -d '{"email": "you@company.com", "password": "secret123", "full_name": "Your Name"}'

2. Login

POST /api/auth/login
curl -X POST http://localhost:8000/api/auth/login \
  -d "username=you@company.com&password=secret123"

3. Track API Calls

POST /api/track
curl -X POST http://localhost:8000/api/track \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{
    "provider": "openai",
    "model": "gpt-4o",
    "input_tokens": 150,
    "output_tokens": 50,
    "latency_ms": 1200,
    "status": "success",
    "project": "my-app"
  }'

Python SDK Example

Python
import httpx

class LLMTracker:
    def __init__(self, base_url, token):
        self.base_url = base_url
        self.headers = {"Authorization": f"Bearer {token}"}

    def track(self, provider, model, input_tokens,
              output_tokens, latency_ms, status="success"):
        return httpx.post(
            f"{self.base_url}/api/track",
            json={
                "provider": provider,
                "model": model,
                "input_tokens": input_tokens,
                "output_tokens": output_tokens,
                "latency_ms": latency_ms,
                "status": status,
            },
            headers=self.headers,
        )

# Usage
tracker = LLMTracker("http://localhost:8000", "your-token")
tracker.track("openai", "gpt-4o", 150, 50, 1200)
